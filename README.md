# NETATM v0.3 — GitHub Pages Demo

Python gerektirmeyen, HTML/CSS/JavaScript tabanlı dijital yayın platformu.

## GitHub Pages ile yayınlama
Settings > Pages > Build and deployment > Deploy from a branch.
Branch: main, Folder: /(root), Save.
Yayın adresi: https://ozkanatmis.github.io/NETATM/

## Özellikler
Mobil uyumlu koyu tema, film/dizi katalogları, arama, favoriler (tarayıcıda saklanır), içerik detayları, örnek video oynatıcı ve Premium etiketleri.

## Önemli
Bu bir ön yüz demosudur. Gerçek kullanıcı hesabı, ödeme, Premium erişim kontrolü, video yükleme veya güvenli medya yayını henüz bulunmaz. Katalog örnektir; ücretsiz içeriklerde tek bir CC0 demo video gösterilir. Görseller Unsplash kaynaklıdır. Gerçek platform için Supabase ve video dağıtım altyapısı sonraki sürümde eklenecektir.
